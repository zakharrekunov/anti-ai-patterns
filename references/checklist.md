# Pre-publish Checklist

Проходи каждый пункт. Hit = фикс. Не пропускать "вроде нормально".

## Pass 0 — смысл

- [ ] Выписал 1-3 мысли текста и кто его читает?
- [ ] Попаданий больше трёх на абзац? → переписывай заново от мыслей, исходник только источник фактов (SKILL.md, шаг 3)
- [ ] У каждого скопления назвал причину (таблица «Почему модель так пишет» в SKILL.md)?

## Pass 1 — словесные паттерны

- [ ] Em/en-dash где-нибудь (— –)? → замени на `,` `.` `()` или перепиши
- [ ] Двойные кавычки вокруг короткой фразы для эмфазиса/примера? → убери, интегрируй фразу в поток
- [ ] Adverbs (`really`, `just`, `literally`, `genuinely`, `honestly`, `simply`, `actually`, `deeply`, `truly`, `fundamentally`, `inherently`, `inevitably`, `interestingly`, `importantly`, `crucially`, `буквально`, `реально`, `честно говоря`, `просто`, `на самом деле`)? → удали те, что ничего не несут. Ловим скопление (2-3 в абзаце), слово со смыслом остаётся
- [ ] Throat-clearing opener (`Here's the thing`, `Here's what`, `Here's why`, `It turns out`, `The truth is`, `Let me be clear`, `The real X is`, `Can we talk about`, `Если честно`, `Знаете что`, `На самом деле…`)? → удали, начни с факта
- [ ] Emphasis crutches (`Full stop.`, `Period.`, `Let that sink in.`, `Make no mistake`, `This matters because`)? → удали
- [ ] Business jargon (`navigate`, `unpack`, `lean into`, `landscape`, `game-changer`, `double down`, `deep dive`, `circle back`, `на одной волне`, `прокачать`, `вызовы`)? → замени plain language
- [ ] Meta-commentary (`Hint:`, `Plot twist:`, `Spoiler:`, `Let me walk you through`, `In this section`, `Сейчас объясню почему`, `Дальше будет интересно`)? → удали
- [ ] Vague declaratives (`The reasons are structural`, `The implications are significant`, `The stakes are high`, `Последствия серьёзные`, `Причины глубже чем кажется`) без конкретики? → назови специфику или вырежи
- [ ] Lazy extremes (`every`, `always`, `never`, `everyone`, `nobody`, `всегда`, `никогда`, `все`, `никто`) без конкретики? → замени или ограничь scope
- [ ] Scientific jargon в peer content (`n=1`, `external validation`, `confirmation bias`, `anecdata`, `statistically significant`, `control group`, `methodology`)? → разговорный эквивалент
- [ ] Filler (`At its core`, `In today's X`, `At the end of the day`, `In a world where`, `The reality is`, `По сути`, `В наше время`, `В конечном счёте`)? → удали

- [ ] Хвост значимости (`…, подчёркивая важность X`, `…, что делает его незаменимым`, `…, highlighting the importance of`, `ensuring a seamless experience`)? → режь или отдельное предложение с настоящей причиной
- [ ] Связка вместо «это/есть» (`является`, `служит`, `выступает в роли`, `представляет собой`, `serves as`, `stands as`, `boasts`)? → «это», «есть», `is`, `has`
- [ ] Модные украшения (`тихо`, `тихая сила`, `честный ответ`, `несущий`, `quietly`, `the honest answer`, `real trade-offs`, `load-bearing`, `doing a lot of work`)? → убери, скажи утверждение

## Pass 2 — структурные паттерны

- [ ] Binary contrast (`Not X. But Y.`, `It's not X. It's Y.`, `Не X, а Y.`, `Дело не в X, дело в Y.`)? → скажи Y напрямую
- [ ] Negative listing (`Not a X. Not a Y. A Z.`, `Не X. Не Y. Это Z.`)? → сразу Z
- [ ] Dramatic fragmentation (`Speed. Quality. Cost.`, `X. And Y. And Z.`)? → нормальные предложения
- [ ] Rhetorical setup (`What if I told you`, `Here's what I mean`, `Think about it`, `А что если…`, `Представьте`)? → сразу мысль
- [ ] False agency (`the decision emerges`, `the culture shifts`, `the data tells us`, `the conversation moves`, `решение приходит`, `культура меняется`, `данные говорят`)? → назови человека / используй "you"
- [ ] Narrator-from-distance (`Nobody designed this`, `This happens because`, `People tend to`, `Никто не задумывал`, `Люди склонны`)? → поставь читателя в комнату, "you"
- [ ] Страдательный подряд, деятель спрятан (`X was created`, `Mistakes were made`, `It is believed`, `Было решено`)? → найди actor, поставь вперёд. Одиночный страдательный, где деятель неважен, остаётся
- [ ] Wh- sentence opener (`What makes…`, `When you consider`, `Where this matters`)? → перестрой, веди подлежащим
- [ ] Sentence начинается с `So,` или `Look,`? → удали preamble
- [ ] Одна вещь под разными именами (`приложение… платформа… сервис`, `the company… the firm`)? → одно слово, повторяй
- [ ] Абзац кончается моралью или пересказом (`В итоге…`, `Ultimately…`, `At the end of the day`, `Делая X, вы получите Y`)? → закончи на последнем факте или просьбе
- [ ] Permission-granting closer (`And that's okay.`, `And that's fine.`, `И это нормально.`)? → удали

## Pass 3 — ритм

- [ ] 3+ предложения подряд одинаковой длины? → разбей одно
- [ ] Каждый параграф заканчивается punchy one-liner? → варьируй
- [ ] Listing три пункта когда хватает двух? → ужми
- [ ] Вопрос задан и тут же отвечен? → дай вопросу подышать или удали вопрос

## Pass 4 — Zak hard rules (см. zak_rules.md)

- [ ] Закрытие на `I'm curious…` / `I'd love to hear…` / `Мне интересно…` + compound question? → закрой на утверждении
- [ ] Открытие `For people who X, [Y]?` / `Для тех, кто X, …`? → перепиши под direct / observational / personal-curiosity
- [ ] Outsider-disclosure в первой строке (`I'm not X but…`, `Я не X, но…`, `Posting from outside`)? → веди наблюдением, контекст во 2-3 абзаце
- [ ] Batch posts: 5+ постов закрываются вопросом? → максимум 2-3, остальные на утверждении
- [ ] X by X (`week by week`, `step by step`, `неделя за неделей`)? → назови, что найдёт читатель (правило 15 в SKILL.md)
- [ ] Tone: звучит как маркетолог? → переписать на форумный голос

Только для текста от лица человека (Reddit, комменты, DM, ответ в письме):

- [ ] 2+ предложения начинаются с `The [noun]`? → дропни артикль, начни с подлежащего (Rule 7)
- [ ] Больше одной дефисной связки (`first-line`, `mood-stabilizing`)? → распиши словами (Rule 8)
- [ ] Ответ разбирает каждый пункт собеседника по абзацу? → ответь на 1-2 главных (Rule 9)

## Pass 4.5 — перекоррекция и выдумка (SKILL.md, «Не перекорректируй» и «Выдумка запрещена»)

- [ ] На месте убранного паттерна встал его родственник (тире → двоеточие, `delve` → `dig into`, «не X, а Y» → «X? Нет. Y.»)? → причина не снята, перепиши фразу целиком
- [ ] Двоеточий-раскрытий больше одного на текст? → ужми
- [ ] Ушёл в рубленые фразы, каждая абзацем? → собери в нормальные предложения
- [ ] Срезал настоящую оговорку о том, чего не знаем? → верни одной фразой
- [ ] Появилась цифра, история, цитата, функция продукта, причина или любой факт, которых не было в исходнике? Сверь итог с исходником по фразе → убери или поставь [заглушку]
- [ ] Все факты, цифры, имена и ссылки исходника на месте?
