# anti-ai-patterns

Скилл для Claude Code: финальная проверка любого текста перед публикацией или отправкой. Убирает следы модели (тире, кавычки-эмфазис, прогрев перед мыслью, «не X, а Y», шаблонные закрывающие вопросы, хвосты значимости, синонимы по кругу) и при этом не перечищает текст до рубленых фраз и не выдумывает факты ради конкретики. Работает с русским и английским.

## Установка

Скопируйте папку в `~/.claude/skills/anti-ai-patterns/` (или в `.claude/skills/` проекта). Вызов: `/anti-ai-patterns` и текст.

```bash
git clone https://github.com/zakharrekunov/anti-ai-patterns ~/.claude/skills/anti-ai-patterns
```

## Что внутри

- `SKILL.md`: процедура, причины паттернов, 20 правил, рекламный режим, защита от перекоррекции и выдумки, скоринг.
- `references/`: чек-лист, жёсткие правила с примерами из реальных ревью, списки фраз и структур, примеры до и после.
- `scripts/slop_check.py`: быстрый линтер на Python без зависимостей. `python scripts/slop_check.py file.md`, `--text "..."`, `--ad` для рекламного текста. Код выхода 1 при жёстких хитах.
